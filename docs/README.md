# Documentation

Design documents, newest first. Each version is kept permanently — earlier
versions are historical records and are never edited in place.

## Conventions

- Current design lives at `ScreenRecon_Design.md`. Older major revisions, if kept, are archived as `ScreenRecon_Design_v<X.Y>.md`.
- Raise the version whenever the released design changes. Corrections and
  additions that do not change scope may be folded into the current version
  before it is released; once released, a version is frozen.
- Every version carries a revision-history table at the top and, from 0.1.0
  onward, a final section listing what changed from the previous version and
  why.
- Never edit a released version in place. Issue a new one.
